# ציור שמגלה חוזקה

הכתובת: https://tzior-gh.vercel.app

ציור מונחה שנמדד ב-12 סימנים בקו, בצבע, בשטח ובזמן, ומגלה חוזקה, את הצל שלה וחוזקה רדומה.
נבנה מהחיתוך של [טיפול באומנות](https://tipulart.vercel.app/) ו[חוזקות וצל](https://id-preview--3c13e98a-f7bc-463a-821e-da9cdc65608c.lovable.app/).
נשען על FEATS (Gantt & Tabone, 1998), VIA (Peterson & Seligman, 2004) ושביל הזהב (Niemiec, 2019).
